## Reflection

1. บัตรกรองหนังบอกว่าผู้ปกครองจะเห็นเฉพาะหนังที่ตรงกับ rating ที่เลือก ส่วน sad path ระบุสิ่งที่ผู้ใช้ควรเห็นเมื่อไม่มีหนังตรงเงื่อนไข คือรายการว่างพร้อมข้อความ `No movies with this rating` ข้อความนี้ช่วยให้ผู้ปกครองรู้ว่าตัวกรองทำงานแล้วและเลือก rating อื่นได้ เทสต์ Cucumber ตรวจว่าผลเป็นรายการว่าง ส่วนข้อความเป็นข้อกำหนดของหน้าจอ Lo-Fi
2. ตอนเขียน `movie_sort` เราใช้ถ้อยคำเดิมของ `Given a movie … is in the catalog` และ `Then I should see no movies` ซ้ำ เพื่อให้ Cucumber ใช้ step definitions ที่มีอยู่ แล้วจึงเพิ่ม step สำหรับการเรียงและตรวจลำดับ ส่วน `movie_filter` มี step definitions แบบ stub เขียนไว้ก่อนรัน Red ครั้งแรกที่พบใน CI จึงได้ `PendingException` [ในรอบ Red](https://github.com/bankjunjan/Scenario-6710301032-6710301047/actions/runs/45567353233) ครั้งต่อไปควรรัน scenario ก่อนเพิ่ม stub เพื่อให้เห็นว่า step ใดขึ้น `UndefinedStepException`
3. เมื่อเทียบร่างกับ intent พบว่าร่างกำหนดให้แจ้ง error เมื่อ rating ไม่ถูกต้อง ทั้งที่ผู้ใช้เลือกจากห้าค่าที่มีอยู่ และกำหนดผลกรณีไม่พบหนังทั้งที่ intent ยังเปิดคำถามนี้ไว้ Customer proxy ช่วยยืนยันว่าต้องสื่ออะไรให้ผู้ใช้เห็นเมื่อผลลัพธ์ว่าง และคำว่า “หนังใหม่” อ้างอิงวันที่ออกฉาย

PR #2 ถูก merge โดยไม่มี review จาก A แม้ CI จะผ่าน สำหรับ PR นี้ให้ A ตรวจ passport และภาพประกอบแล้วกด Approve ก่อน จากนั้นให้ B กด Merge
